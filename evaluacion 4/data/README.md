# Datos

Fuente indicada en la guía: Real or Fake Job Posting Prediction, publicado por shivamb en Kaggle.

https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction

Archivo: `fake_job_postings.csv`. Contiene 17 880 filas, 18 columnas y 866 publicaciones etiquetadas como fraudulentas antes de depurar duplicados.

SHA-256 del archivo utilizado:

```
59253295129d8b6a27607f9904f7d4ddf4dbb0ee35e079c7eb51b58b5e62bf60
```

Para descargar desde esta carpeta de proyecto:

```bash
python descargar_datos.py
```

El CSV se conserva localmente y está excluido de Git. Si la descarga automática falla, descargarlo manualmente desde la página y copiarlo en esta carpeta. No usar otro dataset con el mismo nombre sin verificar el esquema y actualizar las conclusiones.
